## 3. 方法

如图 3 所示，ClothDojo 将操作轨迹生成与视觉外观扩展分开。我们通过专家示范和从自主执行状态采集的人工纠正训练 NOCS 条件化的策略，在仿真中生成操作轨迹；随后筛选成功轨迹，在保持运动不变的条件下随机化外观并重渲染，用于 RGB 策略训练。

![图 3：NOCS 引导的数据生成流程](figures/clothdojo-method-framework.png)

**图 3. NOCS 引导的数据生成流程。** 专家示范 \(\mathcal D_E\) 初始化轨迹策略，策略根据 NOCS 图像、机器人状态和任务指令预测动作块 \(A_t\)。任务指标筛选成功轨迹，并辅助定位需要审查的失败 rollout；从选定状态恢复 VR 操作得到人工纠正 \(\mathcal D_H\)。纠正与原始专家示范聚合后进行监督微调，更新后的策略继续生成轨迹。成功轨迹经视觉随机化重渲染后用于 RGB 训练，记录的运动和动作保持不变。

### 3.1 交互环境与任务

ClothDojo 基于 Newton 物理仿真框架，结合 MuJoCo 机器人动力学与 Style3D 布料求解器，模拟机器人操作中的服装形变与接触。在此基础上，环境支持动态甩动、空中换抓和多步折叠等连续双臂操作。

同一环境既可通过 VR 遥操作采集人工示范，也可批量运行自主策略，在不同服装与初态上收集轨迹。初态复用与执行状态恢复使不同策略可以从相同条件进行比较，也允许操作者从策略遇到的状态继续纠正。已有轨迹可在保持运动不变的条件下重渲染为不同外观，用于后续 RGB 策略训练。

在这一环境中，我们以展平与折叠作为轨迹生成和策略评测的两项任务。

**展平。** 机器人将桌面上的褶皱服装整理为正面朝上的自然展平形态。相对参考方向，绕桌面法向旋转 \(0^\circ\)、\(90^\circ\)、\(180^\circ\) 或 \(270^\circ\) 的四个朝向视为等价，桌面内的 XY 平移不受惩罚。其他平面朝向仍计入方向误差，翻面不属于允许的变换，布料的高度偏差也保留在评价中。

**折叠。** 机器人从确认展平的状态开始，将服装整理为紧凑、平整的层叠结构，不规定唯一的折线、动作次序或终态模板。

### 3.2 NOCS 条件化的轨迹策略

我们将服装在规范形态中的归一化表面坐标（NOCS）映射为 RGB 颜色，作为服装纹理。不同服装上相近的相对位置呈现相近颜色，同一表面点的颜色在形变后保持不变，从而在不改变 VLA 预训练结构的情况下，通过图像隐式提供跨资产共享、对形变稳定的位置先验。

具体地，设 \(v_i\) 为服装规范形态中的顶点，\(v_{\min}\) 与 \(v_{\max}\) 为网格的逐轴边界，其 RGB 颜色为

\[
c_i=\frac{v_i-v_{\min}}{v_{\max}-v_{\min}}.
\]

展平与折叠采用相同的训练流程，包括示范初始化和后续策略更新。我们以预训练的 [\(\pi_{0.5}\)](https://arxiv.org/abs/2504.16054) 初始化轨迹策略 \(\pi_\theta\)，并用 VR 专家示范 \(\mathcal D_E\) 进行监督微调。给定 NOCS 渲染图像 \(I_t^N\)、机器人状态 \(r_t\) 和任务指令 \(l\)，策略预测长度为 \(H\) 的连续动作块：

\[
A_t=(a_t,\ldots,a_{t+H-1})
\sim\pi_\theta(\cdot\mid I_t^N,r_t,l).
\]

每次执行动作块的前 \(h\leq H\) 步后，策略根据最新观测预测下一动作块。微调后的策略在不同服装与初态上独立运行，生成轨迹并发现需要人工纠正的状态。

### 3.3 自主经验与人工纠正

自主执行时，策略可能进入初始示范未覆盖的状态。平台依据任务判据自动筛选自主 rollout，并标记成功与失败（第 4.1 节）。对于需要纠正的轨迹，我们选取介入时刻并恢复对应仿真状态，由操作者通过 VR 示范如何继续操作，得到纠正轨迹 \(\mathcal D_H\)。

我们将人工纠正与原始专家示范聚合为 \(\mathcal D_E\cup\mathcal D_H\)，采用与初始化相同的动作预测目标进行监督微调。专家示范提供完整任务行为，人工纠正补充策略实际遇到的状态下应采取的动作。策略更新使用人类示范的动作；自主 rollout 用于定位纠正状态，并提供下游数据生成所需的成功轨迹。

更新后的策略可以继续执行并采集纠正，新增纠正纳入后续监督训练数据。策略的观测输入与动作块预测接口保持不变。

### 3.4 轨迹筛选与视觉扩展

我们按任务完成判据保留自主生成的成功轨迹（第 4.1 节），并依据记录状态将 NOCS 观测重渲染为普通 RGB 图像。重渲染按轨迹随机化服装材质、场景外观与光照，同时保持机器人和服装的运动及动作目标不变，从而将同一操作扩展为不同外观下的训练样本。

为便于在其他工作站复用已有轨迹，平台还支持将记录的末端运动与夹爪事件重定向为目标机器人的动作表示。

## 4. 实验

### 4.1 评价指标与协议

**展平。** 受 [Cloth Funnels](https://arxiv.org/abs/2210.09347) 启发，我们以对应顶点距离分别度量形变与刚体位姿误差，忽略 XY 平移并接受四个等价朝向。形变距离 \(d_{\mathrm{def}}\) 为平面对齐后当前网格与参考网格的平均顶点距离，对齐保留参考高度；朝向距离 \(d_{\mathrm{rig}}\) 为参考网格在拟合朝向与最近等价朝向之间的平均顶点距离。

两项距离均以参考网格 XY 包围盒的对角线长度归一化。成功要求 \(d_{\mathrm{def}}\leq\epsilon_d\) 且 \(d_{\mathrm{rig}}\leq\epsilon_r\)，阈值由专家终态标定。

**折叠。** 到单一终态模板的距离会惩罚其他合理折法，单独使用紧凑度或矩形度又可能接受揉团等失败。我们从当前布料状态提取面积压缩、全层平整度、顶面矩形完整度、三维材料重叠和贴桌程度五个特征。特征经固定训练统计标准化和温和截断后输入线性模型，得到实数质量评分 \(Q\)。模型以专家终态和 HIL 成功标记状态为正例，以发生 HIL 介入但没有成功标记的原 rollout 终态为负例，并按资产切分训练与验证。状态在 \(Q\geq0.1422866\) 时达标；主成功率要求轨迹中存在连续至少三秒的达标区间，终态成功率要求最后三秒全部达标。这里 \(Q\) 评价当前折叠状态。

**评测协议。** 两项任务均在固定执行预算下报告成功率与终态指标，比较策略时保持评分器和阈值不变。任务结果用于成功轨迹筛选及失败审查，策略更新使用专家示范与人工纠正中的动作监督。

> 作者注：折叠 Q 的现有数据参与过指标迭代，不能作为全新独立的最终测试。其适用范围目前限于已验证的仿真上衣折叠任务；近阈值状态仍需保留分数与可视化审计。

| 对应内容 | 实现、参数与标定状态 |
| --- | --- |
| 交互环境 | Newton 1.5.0 固定 fork 组织机器人与场景，MuJoCo 求解机器人动力学，Style3D 使用基于 projective dynamics 的隐式 Euler 布料求解，当前主执行工作站为 Piper。依赖版本以仓库锁定项为准。 |
| 布料与耦合实现 | 服装采用三角网格，模型包含拉伸、剪切、弯曲、重力、刚体接触、自接触与摩擦。当前为单向耦合，布料反作用力不反馈给机器人。 |
| 资产与工作站 | 服装经筛选和仿真转换后接入环境，机器人工作站与任务分别配置。 |
| 物理步进与抓持 | 默认控制频率为 50 Hz，每步 6 个物理子步；正式实验需核对运行配置是否覆盖默认值。抓持结合限幅弹簧阻尼力与位置、速度松弛；释放后短暂关闭夹爪与布料接触。上述设置为数值与交互近似，不代表真实夹持力或滑脱模型。 |
| 抓持设计依据 | 作者说明：为满足遥操作响应要求而采用较低求解迭代次数时，摩擦抓持在快速运动中会出现布料滑脱，因此采用局部附着抓持。正文交代这一设计取舍，不将其写成已完成的速度或稳定性对照实验。 |
| 展平初态 | 随机三维旋转后固定最高顶点及其一环邻域，自然垂落并释放。生成后排除未稳定、未落桌、异常接触和严重自穿透状态。 |
| 展平参考 | 在扩展支撑面上自由沉降，避免长袖在桌边下垂而成为目标形状；实际执行仍使用原工作台。 |
| 展平执行与阈值 | 上限 60 秒。专家终态按资产赋相同总权重，分别取距离的加权中位数加三倍稳健尺度 \(1.4826\,\mathrm{MAD}\)。阈值为 \(\epsilon_d\approx0.0881082\)、\(\epsilon_r\approx0.0429990\)。 |
| 展平指标来源 | 受 Cloth Funnels 的形变／刚体位姿分解启发，引用键为 `clothfunnels`。该文 §III-B 式 (3)–(4) 分别度量对齐后的形状差异及平面位姿差异；本文按任务约定忽略 XY 平移并接受四个朝向。当前平面 Procrustes 对齐、尺度归一化与专家阈值属于本文采用的具体实现，不表述为逐项照搬原文。 |
| 展平距离计算 | 采用平面 Procrustes 对齐，保留参考高度及顶点对应，不允许反射。设对齐后的参考为 \(\hat G\)，\(\ell\) 为参考 XY 包围盒对角线长度，则 \(d_{\mathrm{def}}=(n\ell)^{-1}\sum_i\lVert x_i-\hat g_i\rVert_2\)。设 \(\bar g_i\) 为去 XY 质心后的参考二维顶点，\(\hat\theta\) 为拟合朝向，\(\Phi=\{0,\pi/2,\pi,3\pi/2\}\)，则 \(d_{\mathrm{rig}}=\min_{\phi\in\Phi}(n\ell)^{-1}\sum_i\lVert R_{\hat\theta}\bar g_i-R_\phi\bar g_i\rVert_2\)。综合距离为 \(d_{\mathrm{comb}}=0.65d_{\mathrm{def}}+0.35d_{\mathrm{rig}}\)。 |
| 折叠评分监督 | 专家终态和 HIL 成功标记状态为正例；发生 HIL 介入但没有成功标记的原 rollout 终态为负例。介入点和纠正轨迹末帧不自动作为负例。数据按资产切分。 |
| 折叠评分特征 | \(x\in\mathbb R^5\)，依次描述面积压缩、全层平整度、顶面矩形完整度、三维材料重叠和贴桌程度。特征由同一资产的已验证展平参考归一化；以固定训练统计计算 \(z_i=3\tanh((x_i-\mu_i)/(3\sigma_i))\)。评分不输入速度、夹爪状态、时间、历史或专家终态。 |
| 折叠评分模型 | \(Q=(w^\mathsf{T}z+b-c)/s\)。这是固定权重的五特征线性模型，没有二次交互项、模型集成或按资产切换。Q 可以为负，不表示成功概率，也不保证随时间单调上升。 |
| 折叠评分数据 | 共 1,135 个状态、268 个资产；拟合集 954 个状态，验证集 77 个，对照集 104 个。采用按资产切分的交叉验证；这些集合参与过指标迭代，不等于最终策略 benchmark 的全新独立测试。 |
| 折叠成功规则 | 唯一阈值为 \(Q\geq0.14228658677130532\)。主成功率要求曾连续达标至少 3 秒；终态成功率要求最后 3 秒全部达标。50 Hz 保存状态下逐帧核验 151 个状态，不做平滑、迟滞或短暂跌落豁免。 |
| 过程诊断 | 展平补充报告过程中曾成功与时间平均距离；折叠补充报告时间平均 Q，以及最高分到终态的下降量。它们用于区分过程表现，不替代终态主指标。 |
| NOCS 表示 | 退化轴使用固定的非零归一化跨度。颜色由规范形态确定，不根据当前褶皱重新归一化。NOCS 提供可见表面的几何相对位置参照，不提供被遮挡表面的观测，也不保证不同服装间严格的语义对应。 |
| 纠正聚合与训练 | 原始专家示范与人工纠正聚合后采用相同的动作预测目标进行 SFT，自主 rollout 动作不进入该更新。已有 strict-40k 聚合配置从预训练模型重新训练；图中的更新箭头表示得到新的策略，不规定必须从上一轮 checkpoint 继续优化。 |
| 数据筛选与评测 | 两项任务采用相同监督训练流程。任务判据用于成功轨迹筛选及失败审查。折叠主成功率与终态成功率均按固定 Q 阈值和三秒持续规则计算。 |
| 数据来源记录 | 人工纠正动作独立保存并关联来源 rollout 与恢复位置；生成数据保留服装、初态和生成策略来源。 |
| 视觉扩展与统计 | 每个视觉版本的外观参数在整条轨迹内固定。离线重渲染不重新推进动力学，仅改变视觉观测，机器人状态、任务指令与动作目标保持不变。唯一物理轨迹及其重渲染视觉版本分别统计，视觉版本不计为新增操作轨迹。数据截取终点尚待确定，见下方核对项。 |
| 跨本体复用 | 重定向转换末端运动与夹爪事件的动作表示；目标机器人能否完成服装任务，仍需通过其与布料的交互执行验证。该支持功能不作为已验证的跨本体任务迁移结果。 |

## 供作者讨论：尚未确定的内容

1. **监督训练的最终配方。** 使用专家示范与人工纠正聚合训练，具体数据规模、增强、初始化、batch 与训练步数以最终选定的实验配置为准。已有 strict-40k 配置为从预训练模型重新进行聚合 SFT；多轮闭环的能力不表述为已完成多轮增益验证。
2. **成功数据的终点。** 两项任务的状态判据已选定，但用于发布时采用首次达标、最佳有效状态或固定终态仍需统一。正式结果应使用固定判据，并保留完整轨迹与裁剪来源。
3. **连续展平—折叠。** 初稿先定义两项任务，尚未编写二者连续执行时的策略与指令切换方式。训练流程一致不自动确定连续执行方式。
4. **物理真实性的证据。** 已核对形变、接触、步进与抓持实现；当前查到的材料尚未提供真实面料参数标定或实物—仿真匹配实验。因此正文描述具体机制与近似，不声称已验证真实物理一致性。初态有效性检查支持状态筛选，视觉重渲染扩展外观条件，二者都不能替代动力学真实性验证。若已有相关实验，再据结果补充相应主张。
