# 论文写作原则

- 目标 venue 为 ICRA；在有限篇幅内优先保留主张、必要定义和直接证据。
- 借鉴 PI（Physical Intelligence）博客的因果逻辑，但采用会议论文更紧凑、准确的表述。
- 中文初稿是内容源；论证收敛后再同步英文 LaTeX。
- 按“具体矛盾 → 直观方案为何不足 → 核心 insight → 证据 → 边界”展开。
- 每节直接说明“是什么、为什么成立”，不写“本节将介绍什么”。
- 每节只服务一个中心判断；先给结论，再给必要解释。
- 每段至少承担定义、因果关系或证据中的一项；删除重复动机和过渡句。
- 可由公式、图或表准确表达的内容不铺成长段文字。
- 不罗列系统组件。只保留支撑问题、方法或结论的技术细节。
- 每组实验检验一个明确主张，使用能够排除其他解释的对照。
- 明确区分事实、实验结果、推断和计划；未冻结的数字不写成贡献。
- 相关工作比较实际任务、动作接口、数据和证据，不比较名义规模。
- 不使用宣传性表述、空泛愿景或未经证实的 first/best 声明。
- 使用简洁、直接、自然的语言；术语只在能减少歧义时引入。
- 引用优先使用论文、官方项目页和源码等一手来源。
