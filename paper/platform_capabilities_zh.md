# ClothDojo 功能与论文表述边界

> 本文档用于整理 ClothDojo 当前具备的功能及其论文表述边界，不直接作为论文正文。状态基于 2026-09-01 的仓库实现和当前讨论；实验尚未完成的数字不应写成论文贡献。

## 整体定位

ClothDojo 不是单独的布料仿真器、数据集或评测脚本，而是一套围绕机器人服装操作构建的仿真、数据生成与策略评测系统。其完整工作流是：

```text
服装与机器人资产
  → 交互任务与随机初态
  → 人类实时遥操或策略闭环执行
  → 统一轨迹记录、审查与干预
  → 数据代理生成新轨迹
  → retarget、增强与随机化重渲染
  → 策略训练与闭环评测
```

其中最核心的环境能力是：**双臂机器人能够在仿真中与服装实时动态交互，同一交互环境既可由操作者遥控，也可由策略闭环执行。** 数据方面最核心的设计是：**利用特权视觉信息生成新的成功轨迹，再保持行为不变生成多样化的普通视觉观测。**

## 一、实时服装交互环境

### 已实现能力

- 以 Newton 1.5 统一机器人、场景和布料交互，Style3D 负责动态布料仿真。
- 支持双臂抓取、释放、拖拽、甩动和局部调整，能够同时表达动态操作与准静态操作。
- 操作者可以通过 OpenXR/CloudXR 实时遥控机器人；策略可以在相同仿真运行时中闭环观察并执行动作。
- 当前记录显示，在单张 RTX 5090D 上可达到约 20 Hz 的端到端遥操交互，足以执行甩动等动态动作。
- 交互过程可保存完整的机器人、动作和布料状态，不依赖仅保存视频的示范格式。

### 任务

- **服装展平**：当前主要数据代理、rollout、评分和实验链路均围绕该任务构建。
- **服装折叠**：已有从展平终态继续采集的配置和状态恢复能力，用户已验证相关交互，当前正在接入正式任务、数据和论文流程。

### 表述边界

- 可以称为“支持双臂机器人与服装实时动态交互的仿真环境”。
- 在折叠的正式任务入口、数据和实验完成前，不宜声称展平与折叠具有完全相同的 benchmark 规模或证据。
- 如果论文将展平与折叠并列为两个主要任务，摘要、引言动机、任务定义、指标和实验均需覆盖二者；不能只在平台介绍中增加“折叠”。

## 二、服装资产与随机初态

### 服装资产

- 上游索引包含 33,158 个外部服装资产。
- 当前 607 个资产经过人工筛选并完成仿真格式转换，可直接进入采集和仿真流程。
- 当前共有 757 个转换后的服装资产，其中 150 个未进入已接受集合。
- 平台提供资产预览、搜索、接受或拒绝、转换状态检查，以及采集数量统计。

### 初态生成

- 对服装施加随机三维旋转，随机选择悬挂点，使其自然垂落并释放。
- 沉降后检查稳定性、桌面接触和异常碰撞，只排除物理无效状态。
- 不主动排除背面朝上、局部翻面、严重自遮挡等困难状态。
- 初态连同随机种子、粒子状态和生成元数据保存，可被后续策略重复使用。
- 支持按资产批量生成和多 GPU 并行生成初态池。

### 表述边界

- 服装模型不是 ClothDojo 原创资产。准确表述是“兼容并筛选外部服装资产”或“提供经过筛选和转换的服装资产集合”。
- 当前初态方法是可保存和复用的随机悬挂—释放过程，不应包装成新的复杂状态生成算法。
- “复杂初态”描述最终状态分布；方法本身应称为随机生成、验证并冻结初态。

## 三、机器人工作站与跨本体能力

### 固定机器人工作站

平台持有五套双臂机器人工作站：

- Piper
- ALOHA2
- ARX X5
- FR3 Duo
- UR5e + Robotiq 2F-85

每套工作站固定机器人安装、home、抓取坐标、控制布局、动力学参数和相机，不由任务临时拼装。

### 轨迹 retarget

- 当前公开入口将 Piper canonical trajectory 转换到 ALOHA2、X5、FR3 Duo 或 UR5e + 2F-85。
- retarget 保留源轨迹的 50 Hz 时间轴、任务空间夹持位置、布料状态和夹爪 attach/release 事件。
- 目标机器人的关节动作经过 IK、目标本体动力学 shooting 和 action-only 冷回放检查。
- 转换后的轨迹仍可进入四视角 LeRobot 导出和 Isaac RTX 随机化重渲染。
- 支持多 GPU 和每 GPU 多常驻 worker 的批量转换。

### 表述边界

- 当前直接遥操、状态恢复和记录合同仍主要针对 Piper。五套工作站与四种 retarget 目标已经实现，不等于五种机器人都已完成直接遥操和策略 rollout 适配。
- retarget 不推进目标机器人与服装的接触仿真，输出明确标记 `collision_checked=false`。
- retarget 验证目标本体的几何和刚体动作可执行性，不证明目标机器人能闭环完成服装任务；任务成功仍需重新仿真验证。
- 如果投稿前多机器人遥操和 rollout 全部适配完成，可以将其提升为环境能力；否则应在 Method 中分别陈述工作站、retarget 和当前直接执行本体。

## 四、远程遥操与多人采集

### 已实现能力

- OpenXR 控制器提供双臂末端控制和夹爪操作。
- CloudXR 负责远程 VR 流传输，WSS proxy 提供浏览器可访问的连接入口。
- Web 控制面统一管理任务、服装、GPU slot、会话启停、设备连接、日志和数据状态。
- 每个 GPU slot 运行一个独立遥操会话；拥有多个可用 slot 时，多名操作者可以同时采集。
- 支持 Pico 4 Ultra、Quest 3、Quest 3S 和 Quest 2 的设备配置。
- 支持抓取触觉反馈、视点移动、控制离合、回 home、场景复位和轨迹录制。
- 遥操会话支持普通示范采集、失败点人工介入和从已有终态继续采集。

### 表述边界

- “多人并行采集”指多名操作者使用相互独立的 GPU slot 和会话，不是多人共同控制同一机器人。
- 引言可以概括为“支持远程并行遥操采集”；Web 转发、端口和设备配置属于 Method 或系统附录。

## 五、统一轨迹与数据生命周期

### Canonical trajectory

- 遥操、策略 rollout 和评测共用 canonical trajectory 格式。
- 轨迹记录完整的 50 Hz 状态与动作，并保留资产、初态、机器人、相机、策略和运行来源。
- 统一格式支持断点恢复、增量发布和失败后继续执行。

### 审查、标注与 HIL

- 轻量审查从保存状态增量渲染视频，不重新运行物理仿真。
- Web 界面支持完整轨迹和片段级 Good/Bad 标注。
- HIL 可以从策略失败轨迹的指定帧恢复状态，由操作者接管并记录后续动作。
- 任务 continuation 可以从已有轨迹终态恢复并继续采集，例如从展平终态开始折叠。

### 数据导出与增强

- 轨迹可以回放为四视角标准 LeRobot v2.1 数据集。
- 支持确定性分片导出，以及不重新编码视频的 shard 合并。
- Piper 轨迹支持双臂中轴镜像增强；状态、动作和标注采用确定性代数变换。
- 可以将同一物理轨迹配对渲染为 NOCS 和纯白观测，用于严格控制输入变量。

### 表述边界

- 统一轨迹格式是连接系统各阶段的基础设施，不宜单独包装成论文的主要算法贡献。
- 镜像增强当前只适用于 Piper，不应泛称为任意机器人上的通用增强方法。

## 六、外观随机化与高保真重渲染

### 已实现能力

- Canonical trajectory 可以通过 Isaac RTX 离线重渲染为四视角高保真视觉观测。
- 逐 episode 随机化服装材质、桌面、地面、环境光照、曝光和光照方向。
- 可选加入不同的 RoboDojo 房间背景。
- 材质和 HDRI 来自固定的 Poly Haven CC0 清单，随机化过程由 seed 确定并可复现。
- 同一物理轨迹可以生成多个视觉版本，便于构造动作完全配对的外观对照。
- 随机化组件可以单独开关，用于服装、桌面、地面和光照的单因素实验。

### 表述边界

- 高保真重渲染只恢复并播放已有机器人和布料状态，不重新模拟布料动力学。
- 当前核心实现是视觉随机化，不应泛称为完整的 domain randomization 或动力学随机化。
- 新物理轨迹扩展状态—动作分布；同轨迹重渲染只扩展视觉分布。论文必须分别统计二者。

## 七、特权视觉数据代理

### 数据路径

```text
NOCS 人类示范
  → SFT 训练数据代理
  → 策略 rollout 与 HIL 改进代理
  → 数据代理从全新随机初态生成轨迹
  → 筛选成功轨迹
  → 随机化高保真 RGB 重渲染
  → 训练普通 RGB 下游策略
```

### 已实现或已有入口的能力

- 将服装规范坐标编码为表面颜色，以普通图像接口向数据代理提供跨资产的位置参照。
- 数据代理从专家示范中进行 SFT，并从全新初态闭环 rollout。
- 失败轨迹和人工介入可以继续用于改进数据代理。
- 成功轨迹进入随机化重渲染，为下游策略提供普通高保真视觉观测。
- 下游策略不接收 NOCS、粒子位置或其他特权状态。

### 表述边界

- NOCS 表示归一化空间位置，不是袖口、领口等人工语义标签。
- NOCS 能否形成有效跨资产对应，需要通过 seen/unseen 资产实验验证，不能只按设计动机断言。
- 当前 200 件服装、每件 4 个初态的 800-case 面板用于评估数据代理，不是下游通用策略的最终 benchmark。
- 最终发布的数据规模和下游评测规模仍需由正式实验确定，不能把规划中的约 1.2 万条轨迹写成已完成结果。

## 八、策略训练与闭环执行

### 已实现能力

- 支持 OpenPI JAX 与 OpenPI-RLinf SFT 训练入口。
- JAX EMA checkpoint 可以经过数值一致性检查转换为统一 PyTorch rollout checkpoint。
- 同一 rollout runner 支持 action chunking 与 RTC 执行。
- 支持远程策略服务和多个策略 endpoint。
- 提供 STEAM evaluator、优势标签与 CFG guided policy 的训练和推理入口。
- 训练、策略服务和 rollout 记录 checkpoint、数据、文本、随机种子和运行环境指纹。

### 表述边界

- ClothDojo 当前不以提出新的通用策略架构为主要贡献。
- STEAM、CFG、RTC 等能力用于构建和比较数据代理或现有策略机制，应按实验问题介绍，不应全部列入平台的首段定位。

## 九、并行数据生成与运行基础设施

### 已实现能力

- 单 world 与 multi-world 使用同一个 rollout runner。
- Multi-world 通过 Newton Worlds、整步 CUDA Graph 和 tiled camera 批量推进仿真与视觉观测。
- 初态生成、策略 rollout、LeRobot 导出、Isaac 重渲染和 retarget 均有多 GPU 或确定性分片入口。
- 多机评测 Coordinator 可以启动策略服务、分配本机或远端仿真 worker、恢复缺失轨迹、离线评分并清理所属进程。
- 失败或中断后可以只补齐缺失 trajectory shard，不必重新运行完整实验。

### 表述边界

- 引言适合说“支持并行数据生成和评测”，不需要列出 GPU、worker、CUDA Graph 或分片实现。
- “可扩展”最终仍需由实际吞吐、完成轨迹数和评测规模支撑，不能仅由并行接口推导。

## 十、评测与可复现比较

### 已实现能力

- 初态、资产、策略种子、执行协议和评分模板可以冻结并校验身份。
- 完整轨迹先保存，Peak、终态、AUC distance、曾成功率、终态成功率和抬起时间随后离线计算。
- 指标变化时可以重新评分已有轨迹，不必重新运行策略。
- 支持两个 condition 的配对汇总、资产等权统计和缺失 case 检查。
- 运行配置可以约束模型、部署、初态集合、执行方式和输出身份。

### 当前边界

- 现有 800-case 面板是数据代理评估，不代表下游通用策略的最终 benchmark。
- 如果展平与折叠都作为主要 benchmark 任务，二者需要分别定义初态、目标、成功判据、评测时长和主指标。
- 离线重渲染可以生成训练数据和视觉诊断，不能替代策略在相应视觉条件下的闭环 rollout。

## 十一、开源与资产来源

- 项目计划公开环境代码、任务接口、机器人工作站入口、服装资产接入方式、生成数据和评测协议。
- 外部机器人、服装、材质和房间资产均需保留来源、固定版本和许可证记录。
- “开源”描述发布方式，不是科学定位；只有公开内容和许可证确认后，才适合在摘要或引言中作为事实声明。

## 十二、论文叙述中的优先级

### 适合在引言首先说明

1. ClothDojo 支持双臂机器人与服装实时动态交互。
2. 同一环境同时支持人类遥操和策略闭环执行。
3. 环境覆盖展平与折叠任务，但两项任务的证据范围应准确区分。
4. 成功轨迹难以通过脚本化规则或纯人工采集扩展，因此引出特权视觉数据代理。
5. 轨迹生成与外观随机化解耦，下游策略不使用特权信息。

### 可以在引言中一句概括

- 多样服装和多种机器人本体。
- 远程多人并行遥操。
- 跨机器人 retarget、数据增强和随机化重渲染。
- 批量策略 rollout 与并行评测。

这些能力如果出现，应沿“交互—采集—处理—训练—评测”的工作流组织，而不是逐项列组件。

### 更适合放在 Method 或系统概览

- 服装资产的实际来源、筛选、转换数量和许可证。
- 随机初态的悬挂—释放过程与有效性检查。
- CloudXR、Web 控制面、GPU slot 和 VR 设备。
- Canonical trajectory 字段、相机和 50 Hz 时间轴。
- Retarget 的 IK、动力学 shooting、夹爪事件门禁和接触边界。
- 镜像增强、LeRobot 分片、Isaac RTX 材质与 HDRI。
- Multi-world、CUDA Graph、worker 和 Coordinator。
- 具体评分指标、冻结面板和统计方法。

### 当前不应直接声明

- ClothDojo 自行生成或设计了服装资产。
- 所有机器人已经完成远程遥操、策略 rollout 和闭环服装任务验证。
- Retarget 后的轨迹已经证明目标机器人能够完成服装任务。
- 当前 800-case 数据代理面板是论文最终 benchmark。
- 外观重渲染增加了新的物理操作经验。
- 折叠与展平已经具有完全对称的数据规模、指标和实验结论。
