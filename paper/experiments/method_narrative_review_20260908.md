## 主线与信息取舍

核心关系是：**介绍交互环境与任务目标，再用人类经验与自主执行扩展操作轨迹，并转换为 RGB 训练数据；评价指标与协议集中在实验开头。**

沿用此前归纳的会议论文写法：先说明具体问题，再给出解决它的设计及必要依据；每段完成一个定义、因果关系或证据说明。已有求解器和训练算法需要解释它们在本文中的作用，不逐项展开内部结构。简洁不能删掉决定任务含义的约束，也不能隐藏未完成实验。

| 小节 | 读者应得到的答案 | 正文保留 | 放入设置或作者注 |
| --- | --- | --- | --- |
| 3.1 交互环境与任务 | 环境基于什么架构，支持哪些操作与轨迹复用，任务目标是什么？ | Newton 框架下 MuJoCo 与 Style3D 的分工；动态双臂操作、VR 示范采集、批量自主执行、初态复用与状态恢复、运动不变的视觉重渲染；展平与折叠目标 | 附着抓持及其设计取舍、网格与接触模型、耦合方向、求解参数、资产转换和初态生成程序 |
| 3.2 NOCS 条件化的轨迹策略 | 如何让已有 VLA 学习服装操作？ | NOCS 的稳定表面参照，原图像接口，连续动作块与示范初始化 | 相机数、动作维数、执行步数等配置 |
| 3.3 自主经验与人工纠正 | 示范覆盖不足后，新增经验怎样用于学习？ | 自主结果与人工纠正的不同作用，回报价值 V 与优势条件更新 | 优势跨度、数据混合比例、条件丢弃率等最终配方 |
| 3.4 轨迹筛选与视觉扩展 | 自主操作怎样成为普通 RGB 策略可用的数据？ | 一段说明成功筛选、按轨迹随机化外观、保持运动与动作目标；跨本体仅一句复用说明，不单列重渲染公式 | 具体材质与光照资产数量、每条轨迹的视觉版本数、时间一致性设置、来源记录字段、物理轨迹与视觉版本分开统计、数据截取终点、跨本体执行验证边界 |

审查已从叙事、技术精度和图文分工三个角度交叉进行，并根据后续作者反馈调整。当前写法保留直接解释方法选择的关系，删除重复引言的一般动机；实现参数与公式展开放入备查，不要求每段都补动机或总结句。尚未完成的标定与实验继续以作者注说明。

**指标来源确认：** 作者明确展平指标受 Cloth Funnels 启发。已核对[原文 §III-B](https://arxiv.org/html/2210.09347#S3.SS2) 的形变／刚体位姿分解，并在指标段开头引用；叙述顺序调整为已有评价思路、本文任务约定及计算概要，不将该分解写成本文原创设计。本文忽略 XY 平移、采用四朝向等价及专家阈值；具体对齐与归一化实现也不默认等同于原文。

**环境叙事：** §3.1 按“仿真架构与物理基础 → 动态双臂操作 → 采集与复用能力 → 任务目标”组织。开头简述 Newton、MuJoCo 与 Style3D 的分工，作为模拟的技术依据，不据此宣称真实物理一致性已获验证。局部附着模型及其设计取舍留在实现备查：遥操作要求及时响应，有限迭代次数下摩擦抓持在快速运动中容易滑脱。网格、接触分量、耦合方向、求解参数、初态生成程序和评分器结构也留在设置中。

**当前章节安排：** 环境与任务不再独立成章，与轨迹生成合并为第 3 节 Method，包含上表的四个小节。第 4 节为实验，指标与协议集中于 §4.1；训练标签和成功筛选在需要处前向引用该节。Q 与 V 的区别随 Q 的定义介绍，不在 Method 提前解释尚未引入的评分器。Fig.3 放在 Method 开头，为后续小节建立整体联系。

**RECAP 与 HIL 叙事核对（2026-09-09）：** 重读 [RECAP 原文 §IV-B 与 §V-D](https://www.pi.website/download/pistar06.pdf#page=5) 后，§3.3 按“自主执行与恢复纠正 → 两类经验如何用于学习 → 策略更新后继续采集”组织。原文将人工纠正作为恢复错误的示范，并直接指定正条件；自主经验则通过结果反馈、价值与优势估计进入训练。本文通过恢复保存状态采集 VR 纠正，与原文在自主执行中在线接管的组织方式区分。当前实现中纠正独立保存，不拼接回自主 rollout，不进入价值拟合或优势估计；正标签是监督指定，不能描述为估计得出的正优势。核对依据为 [RECAP 实现说明](../../docs/recap.md)、[恢复操作](../../src/clothdojo/teleop/restoration.py)、[优势标签](../../src/clothdojo/training/recap_advantages.py)和[条件训练](../../src/clothdojo/training/cfg_model.py)。条件丢弃与数据比例仍留在实现设置，不展开为 HIL 的叙事主线。

**条件训练方案确认（2026-09-09）：** 作者选择完整的正优势、负优势和无优势三种条件。数据的原始优势标签仍为二值，第三种条件由训练时随机丢弃优势标签产生，人工纠正先赋正标签再参与同一丢弃过程。§3.3 已按此修改；当前 HIL RECAP 候选配置仍采用 positive-only，论文方案不表示该配置或实验已经同步。数值设置留在实验设置。

现有图建议做两处小调整，保留已收敛的布局：

1. Fig.3 已将 **All rollouts** 改为 **Eligible rollouts**，并在重渲染模块标出 **Selected successes**。更新分支进入的是经训练标签筛选的轨迹，重渲染则依据独立的数据筛选判据；图注明确区分了两者。
2. Fig.1 的标题可将 **Visual randomization** 放在 **retargeting** 前面，降低跨本体作为主贡献的暗示，不扩大跨本体篇幅。图中服装、轨迹、本体与外观数量应在定稿时按最终口径统一，现有标签不作为数字已冻结的证据。

## 优先新增：任务目标与评价图

这张图能帮助理解 §3.1 的任务目标与 §4.1 的评价约定。按当前顺序，优先放在实验开头的 §4.1 附近，避免在生成方法之前扩大指标篇幅。建议从**单栏宽、上下两个 panel**开始，初步高度预算约 60–75 mm；最终按论文实际缩放后的清晰度调整，不预先固定图号。已有三张图分别占据前三页较大面积，新图宜控制为局部定义图。

**(a) 展平的等价变换。** 用同一件方向可辨的服装俯视图，四个小轮廓表示 0°、90°、180°、270°。在一个轮廓旁以浅色位置副本和双向箭头表示 XY 平移；另给一个偏离四朝向的例子和一个翻面例子。用正反面的颜色或可辨标记区分翻面，少画机器人和环境背景。

- 图形表达“四个等价朝向”“平移不影响评价”“其他角度产生朝向误差”“翻面保留在形变误差中”。
- 不将所有非零误差直接标为失败，二值成功还取决于容差。
- 这部分是任务定义示意，可用矢量轮廓制作；不需要为说明定义运行新的物理实验。

**(b) 折叠的多种完成形态。** 同一服装的两个经确认的合理专家终态并列，再配一个紧凑但仍明显褶皱或未整理好的状态，说明为什么不能仅用单一模板距离或紧凑度判断完成。使用记录状态，统一尺度和视角；层叠难以看清时采用略倾斜视角。

- 两个合理终态应体现折线或层叠结构差异，不能用刚体旋转后的同一折法充当多解。不同形态应由实际素材支持，不能只凭“看起来整齐”推断合理完成。
- 任务定义图不标具体 Q 数值或用勾号暗示评分器验证结果；明确这些画面说明任务目标，评分器证据另在实验中报告。
- 若同一服装素材不足，先只做展平定义图，避免通过换服装制造多解性的表面证据。

建议图注主句：**展平评价保留四个等价朝向并忽略平面平移，折叠允许不同的紧凑、平整层叠形态。** 后续分别交代两组画面的身份与误差含义，不重复全部公式。

| 内容 | 建议 | 图应表达什么 |

| NOCS 随形变保持表面位置参照 | 优先利用 Fig.1 的配对画面，必要时加少量对应标记 | 同一表面区域在不同时刻保留身份，同一状态的 NOCS 与 RGB 只改变观测 |

| 物理环境组成 | 当前不新增求解器框图 | §3.1 用一句交代 Newton、MuJoCo 与 Style3D 的分工，再介绍操作能力；独立框图带来的额外信息有限 |
| 物理真实性 | 有匹配实物证据后再做实验图 | 同一操作的真实与仿真对应时刻，配一个事先定义的形状或动态量对比，区分参数标定和独立验证 |
| 折叠 Q 的可信度 | 作为实验结果图候选 | 展示验证状态的评分与完成标签关系，标注固定阈值及三秒规则；说明现有集合参与过指标迭代，定义示意图不能替代这一证据 |
| 跨本体、机器人清单、VLA 结构、资产规模 | 本轮不新增专图 | 跨本体为数据复用支持功能；其余已有总览或正文足以说明 |

后两类实验图只有在对应结果准备好时才考虑，不能用装饰性曲线补齐。当前配图优先级是任务定义，其次才是有证据的评价验证。
